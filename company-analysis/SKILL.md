# 기업 분석 (Company Analysis)

기업의 사업 구조, 재무, 경쟁환경, SWOT, 전략적 시사점을 분석하여 마크다운 보고서를 자동 생성한다.

## Phase 0: 작업 디렉토리 고정 및 사용자 입력 수집

### Step 0-0: 작업 디렉토리 고정

스킬 실행 즉시 `pwd` 명령을 실행하여 호출 시점의 절대 경로를 `WORK_DIR`로 저장한다.  
이후 모든 파일 작성은 `$WORK_DIR/reports/{기업명}.md` 절대 경로를 사용한다.  
**MUST**: 사용자 입력 수집 전에 반드시 먼저 실행한다.

### Step 0-1: 필수 정보 수집

`AskUserQuestion` 도구로 아래 3가지를 한 번에 요청한다:

```
기업 분석을 시작하겠습니다. 아래 필수 정보를 입력해주세요.

[필수]
1. 기업 이름 (예: OTIS, 삼성전자, 현대자동차)
2. 활용 목적 (예: 인턴십 준비, 투자 검토, 취업 면접, 사업 협력 검토)
3. 나의 상황 (예: OTIS 3개월 인턴십 예정 신입사원, 면접 준비 중인 취준생)
```

### Step 0-2: 선택 정보 수집

`AskUserQuestion` 도구로 아래 선택 항목을 요청한다:

```
[선택] 지정하지 않으면 기본값으로 진행합니다.

4. 검색 기간 (기본값: 최근 1년)
5. 톤앤매너
   A. 학술·공식형 — 논문·보고서 문체, 객관적 3인칭, 수치 중심
   B. 전문 실무형 — 비즈니스 문서 문체, 핵심 중심, 간결한 불릿 (기본값)
   C. 친근 학습형 — 쉬운 설명, 비유 활용, 신입·학생 눈높이
6. 분량 (기본값: A4 10페이지)
```

### Step 0-3: 설정 확인

수집된 정보를 요약하여 사용자 확인 후 진행:

```
📋 분석 설정 확인
- 기업: {기업명}
- 활용 목적: {활용목적}
- 나의 상황: {나의상황}
- 검색 기간: {검색기간}
- 톤앤매너: {톤앤매너}
- 분량: {분량}
- 출력 경로: {WORK_DIR}/reports/{기업명}.md

위 설정으로 분석을 시작할까요?
```

## Phase 1: 기초 자료 수집

`mcp__brave-search__brave_web_search`로 아래 항목을 병렬 수집한다.

| 항목 | 검색 쿼리 |
|------|----------|
| 기업 개요 | "{기업명} 회사 개요 연혁 대표자 {검색연도}" |
| 사업 모델 | "{기업명} 사업 구조 수익 모델 매출 {검색연도}" |
| 핵심 제품/서비스 | "{기업명} 주요 제품 서비스 라인업 {검색연도}" |
| 재무 실적 | "{기업명} 매출 영업이익 실적 {검색연도}" |
| 경쟁 환경 | "{기업명} 경쟁사 시장점유율 산업 분석 {검색연도}" |
| 최신 뉴스 | "{기업명} 최신 뉴스 전략 {검색연도}" |
| SWOT | "{기업명} SWOT 분석 강점 약점 기회 위협" |

**MUST**: 각 검색 결과에서 출처 URL과 발행연도를 반드시 기록한다.  
**MUST NOT**: 출처 미상의 수치를 보고서에 기재하지 않는다.

### Step 2-2: 재무 자료 수집 (한국 상장기업만)

```
- 최근 재무제표: mcp__dart-mcp__get_financial_statement

```

**MUST**: 수집된 모든 재무 수치에 "출처: DART 공시, {연도}" 명시.

## Phase 4: 보고서 작성

### 출력 경로 생성

```bash
mkdir -p $WORK_DIR/reports
```

출력 파일: `$WORK_DIR/reports/{기업명}.md`

### 보고서 목차

아래 9개 섹션을 모두 포함하여 작성한다.  
톤앤매너·분량은 Phase 0에서 수집한 사용자 설정을 적용한다.

```
# {기업명} 기업 분석 보고서
> 분석 목적: {활용목적}
> 작성 기준일: {오늘날짜}
> 검색 기간: {검색기간}

# 1. 요약
- "{활용목적}" 관점의 핵심 전략적 시사점 5개 이내
- 각 시사점에 근거 데이터 1~2줄 명시

# 2. 기업 개요
- 설립연도, 본사 위치, 대표자 (출처 명시)
- 임직원 수 (출처 명시)
- 지배구조 및 주요 주주
- 조직 구조 개요
- 주요 지점/법인/매장 현황

# 3. 사업 모델 분석
## 3.1 수익 구조
- 사업 부문별 매출 비중 (출처·연도 명시)
## 3.2 핵심 제품/서비스
## 3.3 고객 세그먼트
## 3.4 판매 채널

# 4. 재무 및 성장성
## 4.1 매출·영업이익·순이익 추이
- 최근 3개년 실적 테이블 (출처·연도 필수)
## 4.2 성장률과 수익성
- YoY 성장률, 영업이익률, 순이익률
## 4.3 현금흐름 및 부채 리스크
- 부채비율, 유동비율, 주요 재무 리스크

# 5. 경쟁 환경
## 5.1 주요 경쟁사 비교 (최소 3개사)
- 비교 테이블: 기업명 / 매출 / 시장점유율 / 주요 강점 (각 출처 명시)
## 5.2 차별화 요소
- {기업명}만의 경쟁 우위 3가지 이상
## 5.3 시장 내 위치
- 시장 점유율 또는 시장 내 위상 (출처 명시)

# 6. SWOT 분석
| 구분 | 내용 | 근거 |
|------|------|------|
| 강점 (S) | (3개 이상) | 각 근거 명시 |
| 약점 (W) | (3개 이상) | 각 근거 명시 |
| 기회 (O) | (3개 이상) | 각 근거 명시 |
| 위협 (T) | (3개 이상) | 각 근거 명시 |

# 7. 리스크 및 기회
## 7.1 주요 리스크
## 7.2 성장 기회

# 8. 전략적 시사점
## 8.1 "{활용목적}" 관점의 기회
## 8.2 주의할 점
## 8.3 다음 액션 제안
- {나의상황}에게 실질적으로 도움이 되는 구체적 액션 3~5개

# 9. 출처
| # | 출처명 | URL | 발행연도 |
|---|--------|-----|---------|
```

### 작성 규칙

**MUST**:
- 모든 수치·인용에 출처와 발행연도를 괄호 또는 각주로 명시
- 확인된 사실과 추정을 구분 표기 (추정은 "(추정)" 명시)
- 전문용어에 쉬운 해설을 각주로 추가
- 명사체 사용 ("~한다" → "~함")
- 한 줄 120자 이내

**MUST NOT**:
- 출처 없는 수치 기재 금지
- 추측성 단정 표현 금지
- 9개 섹션 중 일부 생략 금지
